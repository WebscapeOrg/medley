# Medley 0.1.0 validation

Validated on Linux with Python 3.14, Chromium, herdr executable 0.9.3 and running server 0.9.1. macOS playback uses afplay but has not been exercised on a Mac. Windows is not advertised as supported.

## Automated and live evidence

- Eleven Python tests pass: default resolution, configured status defaults, quiet/reset and workspace isolation, invalid rules, invalid uploads, copied/deduplicated imports, initial silence and event deduplication, disabled no-op, activation/disable restoration, failure rollback, atomic/private persistence.
- Browser end-to-end checks pass: upload, per-workspace selections, quiet mode, persistence after reload, individual reset, reset-all/undo, native audio preview loading, missing-file error recovery, mobile overflow check, keyboard focus, unauthorized API read/write rejection, no JavaScript errors.
- `node --check assets/app.js` passes.
- The actual herdr 0.9.1 server accepts the manifest and executes the status hook successfully. A temporary synthetic workspace was reported working then blocked; Medley's persisted combined status became blocked. All its rules were quiet during this test. The workspace and temporary rules were removed afterward. Other agents were not controlled.
- Herdr config validation and reload succeeded after Medley took ownership of playback. No server or desktop-shell restart occurred.
- MP3 decoding is tested through ffprobe. This does not constitute a human listening test or proof that every audio device is audible.

Reproduce: `python3 -m unittest discover -s tests -v`. For browser checks: `npm ci`, `npx playwright install chromium`, `npm test`. On a host with Chromium already installed, set `CHROMIUM_PATH` to that executable. Screenshots use only the synthetic browser fixture and are regenerated by the browser check.

## Interface block contract

The interface is bespoke HTML/CSS, not a vendored UI block. Desktop status rows have four grid children: label, selector, preview and reset. At narrow widths the label and selector span the row and actions wrap below. Rendered desktop and 390px mobile captures verify the arrangement. No vendored-block structural invariant applies.

## Known limits

Server-host playback only; no client-specific routing or focus suppression. Rapid intermediate transitions coalesce; overlapping clips are dropped. Independent sessions need separate config/state directories. A new/deleted-and-recreated workspace does not inherit old mappings. Screen-reader operation, macOS and real audio-device listening remain unverified. These limits are disclosed in README and the interface where relevant.
